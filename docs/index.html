Установить значок «Федя VPN» на экран

🤖
Android · Chrome
  1. Открой эту страницу в Chrome (без магазина приложений).
  2. Нажми кнопку ниже — появится системное предложение «Установить».
  3. Если кнопка неактивна — открой меню Chrome (⋮) → «Добавить на главный экран».
🍎
iPhone · Safari
  1. В боте «Федя» нажми «Установить на iPhone» — придёт файл‑профиль.
  2. Открой полученный файл в чате.
  3. Настройки → Профиль загружен → Установить (профиль без подписи, это ожидаемо — просто веб‑ярлык, а не сторонний код).
Файл нельзя раздать прямой ссылкой — iPhone распознаёт профиль только когда получает его как файл, поэтому он приходит через бота.
